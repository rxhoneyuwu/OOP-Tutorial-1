#Course Description
This subject teaches students how to code using the Java programming language. This subject covers the fundamental principles, which include:

1. Classes and Objects: Where it talks about blueprints and instances.
2. Encapsulation: Hiding the Data and having access to the control
3. Inheritance: Creating class relationships hierarchically.
4. Polymorphism: Many forms of objects and methods
5. Abstraction: Hiding private details
6. File I/0: Reading and writing data to files
7. Collections: Managing a group of objects using the ArrayList
8. GUI Programming: Creates graphic interface for users with Swing

With all of these topics, students were given hands-on tutorials to do in GitHub, which helped them understand further on the topics as well as being able to solve real world situations. These tutorials also help with portfolio development for students.
